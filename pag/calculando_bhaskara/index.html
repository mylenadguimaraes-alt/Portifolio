Equação de Segundo Grau

Como funciona?

Uma equação de segundo grau possui a seguinte forma:

ax² + bx + c = 0

Para encontrar as raízes da equação, utilizamos a fórmula de Bhaskara. Primeiro calculamos o valor de Delta (Δ):

Δ = b² - 4ac

Depois, calculamos as raízes utilizando:

x = (-b ± √Δ) / 2a
